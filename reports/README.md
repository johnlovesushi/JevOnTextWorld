# 实验报告

每个实验运行对应两个文件，都由 `scripts/summarize_run.py` 根据 `runs/<ID>/` 自动生成：

- `<ID>.md`：给人看的报告。章节固定：运行信息、非默认配置、Anomalies（自动检测的异常）、
  Validation、Training（前 10 个和后 10 个 batch 的均值）、Log tail、Executor notes。
- `<ID>.json`：同样的数据，用来对比不同的运行。

自动检测的异常包括：

- loss 或梯度范数不是有限值
- 运行没有完成
- 没有任何学习信号（所有组的优势都是 0）
- λ=0 时没有一组同时有胜有负
- 采样时和训练时的 log-prob 差别大于 0.05
- 最后一遍的平均裁剪比例大于 0.2
- 没有验证集评测
